# Protocol-Stego Dataset

This is the current protocol_stego dataset, generated by the current
experiment code and verified by `DATA_QUALITY_REPORT.md` and
`BASELINE_ANALYSIS.md`.

## Raw

`raw/normal/` and `raw/stego/` each contain 23 sessions.

Each session keeps:

```text
metadata.json
session_config.json
sender.jsonl
receiver.jsonl
errors.jsonl
sender_result.json
receiver_result.json
```

Raw JSONL files are preserved without modification.

## Processed

```text
processed/X.npy          # [138, 4, 128], float32
processed/y.npy          # [138], int64
processed/windows.npz    # X and y in npz form
processed/index.jsonl    # session_id, window_id, label, start/end event
processed/build_summary.json
processed/stats.json
processed/data_quality_report.json
processed/baseline_analysis.json
```

Feature order:

```text
0 direction
1 length
2 inter_arrival_time
3 cumulative_bytes
```

## Splits

```text
splits/train.npz / train_index.jsonl
splits/val.npz   / val_index.jsonl
splits/test.npz  / test_index.jsonl
splits/split_manifest.json
```

These are the already validated session-level splits. Do not randomly
re-split windows.

Current split:

```text
train: 38 sessions, 114 windows
val:    4 sessions,  12 windows
test:   4 sessions,  12 windows
```

## Labels and Caveats

```text
0 = Normal
1 = Stego = current 800/1200 application-layer length modulation
```

Current caveats:

- `direction` is constant +1 because only Client → Server traffic was
  recorded;
- Normal length is mostly 1024 B;
- Stego length is 800/1200 B;
- the current task mainly tests detection of the 800/1200 modulation
  signature, not general steganography detection.
