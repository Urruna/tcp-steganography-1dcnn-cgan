# Data Generation

## Current protocol_stego Pipeline

```bash
cd src/protocol_stego
docker compose build

docker compose run --rm tests python scripts/run_experiment.py \
  --mode both --normal 20 --stego 20 \
  --seed 42 --secret-size 16 --block-gap-ms 20 --window-size 128

docker compose run --rm tests python scripts/dataset_builder.py --window-size 128
docker compose run --rm tests python scripts/split_dataset.py \
  --val-ratio 0.1 --test-ratio 0.1 --seed 42
docker compose run --rm tests python scripts/dataset_stats.py
docker compose run --rm tests python scripts/data_quality_report.py
docker compose run --rm tests python scripts/baseline_analysis.py
```

## Session Generation

`scripts/session_runner.py`:

1. generates deterministic secret for Stego;
2. AES-256-GCM encrypts the secret;
3. splits ciphertext into frames;
4. encodes frames and converts to bitstream;
5. Proxy-A writes 800/1200-byte blocks;
6. Proxy-B recovers bits, decodes frames, reassembles and decrypts;
7. writes raw JSONL and metadata.

Normal sessions skip the modulation and use normal 1024-byte chunks.

## Dataset Builder

`scripts/dataset_builder.py`:

- reads `receiver.jsonl`;
- uses `observed_length` as the `length` feature;
- creates non-overlapping 128-event windows per session;
- never crosses session boundaries;
- writes `windows.npz`, `index.jsonl`, `build_summary.json`.

## Split

`scripts/split_dataset.py`:

- splits by `session_id`, not by window;
- 80/10/10 default ratios;
- checks overlaps;
- writes train/val/test npz and index files.
