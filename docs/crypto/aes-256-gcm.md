# AES-256-GCM

## Algorithm

Implementation: `src/crypto/crypto.py`

Algorithm: AES-256-GCM (AEAD).

## Format

```text
Header(1B) | Flags(1B) | Nonce(12B) | Ciphertext | Tag(16B)
```

Fixed overhead:

```text
1 + 1 + 12 + 16 = 30 bytes
```

## Key

- `keygen()` → 32 random bytes (`os.urandom`);
- `derive_key(passphrase)` → PBKDF2-HMAC-SHA256, default 200000 iterations;
- default salt: `newtry97-crypto-v1`;
- current experiment uses a pre-shared key or deterministic derived key.

Not implemented: key exchange, key rotation, random per-session salt.

## Nonce

- 12 random bytes per message;
- transmitted inside the ciphertext blob;
- must never be reused with the same key.

## Authentication Tag

- 16 bytes;
- generated by AES-GCM;
- wrong key or modified ciphertext raises `CryptoError`.

## API

```python
from crypto import encrypt, decrypt, keygen, derive_key

key = keygen()
blob = encrypt(b"message", key)
plain = decrypt(blob, key)
```

Fixed-length mode:

```python
blob = encrypt(b"message", key, pad_to=64)
```

## Encryption Flow

```text
plaintext
 → optional length prefix + zero padding
 → AES-256-GCM(key, nonce)
 → Header + Flags + Nonce + Ciphertext + Tag
```

## Decryption Flow

```text
blob
 → check Header/Flags
 → extract nonce
 → AES-256-GCM decrypt + tag verification
 → optional padding removal
 → plaintext
```

## Limitations

- content confidentiality only;
- does not hide traffic features;
- fixed KDF salt in experiment mode;
- no key exchange / rotation.
